# MT PowerDrumKit VST — Sample & Groove Guide for Cosmic Blues Setlist

## Overview
MT PowerDrumKit is a free VST/AU/AAX drum sampler with a single, high-quality acoustic drum kit sound. Unlike multi-kit plugins, it has ONE kit — but it sounds great in any mix because the samples are pre-processed with compressors and EQ. The power is in the **Groove Library** — thousands of MIDI grooves and fills you can drag into your DAW.

This guide tells you which MT PowerDrumKit grooves and settings to use for each of the 30 songs.

---

## MT PowerDrumKit Key Concepts

1. **The Kit** — One drum kit, pre-processed. Sounds great for pop, rock, metal. For blues, it works well with some adjustments (see below).
2. **Groove Library** — Built-in browser with thousands of MIDI grooves organized by genre/style. Search by genre (Rock, Pop, Metal) and feel (8th, 16th, shuffle).
3. **Fills** — Library also includes fills you can drag between grooves.
4. **Built-in Compressors** — Each channel (kick, snare, etc.) has its own compressor. Adjust for blues.
5. **MIDI Output** — You can export the groove as MIDI to edit in your DAW's piano roll.

## Global Settings for Blues

### Mixer Settings
| Channel | Volume | Compressor | EQ Notes |
|--------|--------|------------|---------|
| **Kick** | 0 dB | On, medium | Full, punchy but not boomy |
| **Snare** | +2 dB | On, medium | Crack but not harsh — essential for blues backbeat |
| **Hi-Hat** | -3 dB | Off | Blues needs hats present but not dominant |
| **Ride** | -2 dB | Off | For slow blues, ride replaces hat |
| **Toms** | -3 dB | Off | Only used in fills |
| **Crash** | -4 dB | Off | Sparse — only on section changes |
| **Overhead** | -6 dB | Off | Subtle room sound |
| **Room** | -8 dB | Off | Minimal — blues doesn't need huge room sound |

### Tips for Blues Tone
- **Less compression** than rock — blues drums should breathe more
- **Lower overheads** — you want close-mic intimacy, not arena reverb
- **Snare slightly up** — the backbeat IS the blues feel
- **Kick warm, not clicky** — turn down beater attack if option exists
- **Turn OFF any reverb** on the snare — blues drums are dry

## Groove Library Search Tips

### MT PowerDrumKit doesn't have a "Blues" category — use these instead:
1. **Pop > Shuffle** = your go-to for blues shuffle (most songs)
2. **Pop > Ballad** = slow blues
3. **Rock > 8th Note** = blues-rock, medium energy
4. **Rock > 16th Note** = fast blues-rock, high energy
5. **Rock > Shuffle** = blues-rock shuffle (heavier than Pop > Shuffle)

### Finding the Right Groove
1. Search by category (e.g., Pop > Shuffle)
2. Filter by tempo (enter your song's BPM)
3. Preview by clicking the groove
4. Listen for: kick on 1 & 3, snare on 2 & 4, swung 8th hats
5. Drag onto MIDI track when you find the right one

### If You Can't Find the Perfect Groove
1. Pick the closest match
2. Export as MIDI (right-click → Export MIDI)
3. Edit in your DAW's piano roll:
   - Move hats to swung positions (drag 8th notes slightly late)
   - Add ghost notes on snare for shuffle feel
   - Adjust kick pattern to match the song
4. Save as a custom MIDI file for future use

## DAW Setup (Quick)

### Reaper
1. Insert MT PowerDrumKit on a new track (FX → VST → MT PowerDrumKit)
2. Create a MIDI track routed to the MT PowerDrumKit track
3. Drag groove from MT PowerDrumKit library onto the MIDI track
4. Set project tempo to match song BPM
5. Adjust mixer levels in MT PowerDrumKit's built-in mixer

### Ableton Live
1. Create a MIDI track
2. Add MT PowerDrumKit as instrument
3. Drag groove from library into a clip
4. Set tempo
5. Use the plugin's mixer for levels

### Cubase / Nuendo
1. Add MT PowerDrumKit as VST Instrument
2. Create MIDI track routed to it
3. Drag groove from library into the track
4. Set tempo

## Using the Custom Drum MIDI Files

You already have 30 custom drum MIDI files in `blues/midi/`. You can load these directly into MT PowerDrumKit:

1. Drag the MIDI file (e.g., `12-stormy-monday.mid`) onto a MIDI track in your DAW
2. MT PowerDrumKit will play it using its drum samples
3. The MIDI files use standard GM drum mapping — compatible with MT PowerDrumKit's default mapping
4. Adjust tempo in your DAW to match (tempo is also embedded in the MIDI file)

### Why Use Custom MIDI vs Groove Library?
- **Custom MIDI** (blues/midi/) — Tailored to each song's exact structure (12-bar or 8-bar), tempo, and feel. 3 choruses with fills. Ready to go.
- **Groove Library** — More realistic feel (real drummer recorded), better sound, but you'll need to search and audition to find the right match.

**Recommendation**: Try the Groove Library first for better realism. Fall back to custom MIDI if you can't find a good match.
