# Boss RC-10R Setup Guide — Cosmic Blues Band Setlist

## Overview
This guide walks you through setting up your Boss RC-10R Rhythm Loop Station for all 30 songs in the Cosmic Blues Band repertoire. The RC-10R has 99 memory slots — more than enough for the full setlist.

## RC-10R Key Features
- **99 memory slots** — each stores a rhythm + loop settings
- **280+ onboard rhythm styles** — with song structure (intro, patterns, fills, ending)
- **16 drum kits** — change the sonic flavor of any rhythm
- **50 user rhythm locations** — import custom SMF (Standard MIDI File) rhythms via USB
- **Two-track looper** — serial loop engine synced to rhythm
- **MIDI I/O** — mini TRS jacks for sync and control
- **32-bit processing** — studio-quality sound

## Quick Start: Setting Up a Song

### Step 1: Choose a Memory Slot
1. Press **MENU** → scroll to **Memory**
2. Use **VALUE knob** to select an empty slot (01-99)
3. Press **EXIT** to return to main screen

### Step 2: Select the Rhythm
1. Press **RHYTHM switch** (left switch) to enter rhythm mode
2. Use **VALUE knob** to scroll through 280+ rhythm styles
3. For blues, look for styles in these categories:
   - **Blues Shuffle** — for most Chicago blues songs
   - **Slow Blues** — for ballads like Stormy Monday, Thrill Is Gone
   - **Rock** — for blues-rock like Crossroads, Sunshine of Your Love
   - **Boogie** — for Boom Boom, La Grange

### Step 3: Set the Tempo
1. Press **MENU** → **Tempo**
2. Use **VALUE knob** to set BPM (or tap tempo with CTL1 footswitch)
3. Match the tempo from your setlist (see table below)

### Step 4: Choose a Drum Kit
1. Press **MENU** → **Rhythm Kit**
2. Use **VALUE knob** to select from 16 kits:
   - **Standard** — clean studio kit (good default)
   - **Power** — heavier rock kit (for Crossroads, Bad to the Bone)
   - **Brushes** — for slow blues, senior audiences
   - **Vintage** — warmer, older sound (for Delta blues)
   - **Tight** — dry, punchy (for shuffle feel)

### Step 5: Set Song Structure
1. Press **MENU** → **Rhythm Pattern**
2. Set **Pattern 1** — main verse groove (e.g., shuffle)
3. Set **Pattern 2** — chorus/solo groove (e.g., same but with fills)
4. Set **Intro Fill** — opening fill
5. Set **Ending Fill** — outro fill

### Step 6: Save to Memory
1. Hold **MENU** button for 2 seconds → **Write**
2. Select memory slot number
3. Press **MENU** to confirm

### Step 7: Test and Adjust
1. Press **RHYTHM switch** to start rhythm
2. Use **RHYTHM LEVEL knob** to set volume
3. Use **CTL1/CTL2** to switch between Pattern 1 and Pattern 2
4. Adjust tempo or kit as needed, then re-save

## Recommended Rhythm Styles (Onboard)

The RC-10R has 280+ styles. Here are the ones that map best to blues:

| Rhythm Style Category | Best For | Songs |
|----------------------|----------|-------|
| **Blues Shuffle** | Standard Chicago blues | Going Down, King Bee, Mannish Boy, Dust My Broom, Hoochie Coochie, Alabama Train, Champagne & Reefer |
| **Slow Blues** | Ballads, minor blues | Little Red Rooster, Rock Me Baby, Red House, Stormy Monday, Thrill Is Gone, Born Under Bad Sign, Spoonful, Sweet Little Angel |

If you can't find an exact match, **Blues Shuffle** at the right tempo works for 80% of the setlist.

## Importing Custom Drum MIDI (Optional)

You can import the 30 custom drum MIDI files from `blues/midi/` into the RC-10R's 50 user rhythm locations.

### What You Need
- **Boss RC-10R Manager** software (free download from boss.info)
- USB micro-B cable

### Steps
1. Download and install **RC-10R Manager** from https://www.boss.info/global/products/rc-10r/downloads/
2. Connect RC-10R to computer via USB
3. Open RC-10R Manager — it will detect your pedal
4. Go to the **User Rhythm** tab (50 slots available)
5. Drag and drop MIDI files from `blues/midi/` into user slots
6. Click **Write** to save to the pedal
7. On the RC-10R, select the user rhythm via MENU → Rhythm → User

### MIDI File Notes
- The generated MIDI files use GM drum mapping (standard)
- Each file has 3 choruses of the 12-bar (or 8-bar) form
- Intro fill + 3 choruses + outro fill
- Tempo is embedded in the MIDI file
- The RC-10R can use these as custom rhythms with full song structure

## Live Performance Workflow

### Before the Gig
1. Walk through all 30 memory slots and verify each rhythm sounds right
2. Set **RHYTHM LEVEL** to match your amp volume
3. Test the **CTL1/CTL2** footswitches for pattern switching
4. Make sure tempo is correct for each song

### During the Gig
1. **Select the memory slot** for the next song (use VALUE knob)
2. **Press RHYTHM switch** to start the drum pattern (intro fill plays)
3. **Play the song** over the rhythm
4. **Press CTL1** to switch from Pattern 1 → Pattern 2 for solos
5. **Press CTL2** to trigger a fill when changing sections
6. **Press RHYTHM switch** to stop (ending fill plays)

### If Using the Looper
1. Press **LOOP switch** to start recording (plays in sync with rhythm)
2. Record your guitar riff or chord progression
3. Press **LOOP switch** again to close the loop
4. The loop plays in sync with the rhythm
5. Press **LOOP switch** to stop/overdub as needed
6. Use the **second loop track** for a different section (verse vs chorus)

### Quick Song Change
- Use **VALUE knob** to scroll to next memory slot between songs
- The rhythm auto-loads when you select a new slot
- Takes about 2 seconds — fast enough between songs

## Recommended Footswitch Setup

Connect an **FS-7** dual footswitch to the CTL 1, 2/EXP jack:

| Footswitch | Function | Why |
|-----------|----------|-----|
| **CTL1 (left)** | Pattern 1 ↔ Pattern 2 | Switch between verse and solo grooves |
| **CTL2 (right)** | Fill | Trigger fills at section changes |

Alternatively, connect an **expression pedal** (EV-30 or Roland EV-5) for rhythm volume control — useful for fade-ins/outs.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Rhythm too quiet | Turn up RHYTHM LEVEL knob |
| Rhythm too loud / drowns guitar | Turn down RHYTHM LEVEL, or use dual outputs (Output A = guitar, Output B = rhythm) |
| Tempo feels wrong | Check BPM in MENU → Tempo against setlist |
| Shuffle feel too stiff | Try a different Blues Shuffle style, or adjust swing in MENU |
| Need different drum sound | Change Rhythm Kit (MENU → Rhythm Kit) |
| Can't find right blues style | Import custom MIDI from blues/midi/ via RC-10R Manager |
| Looper out of sync | Always start rhythm FIRST, then record loop — loop auto-syncs to rhythm |
