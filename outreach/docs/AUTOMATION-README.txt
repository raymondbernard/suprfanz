## 🛠️ Troubleshooting

**Chrome doesn't open?**
- Close all Chrome windows first
- Check Profile 3 exists

**Fields don't fill?**
- Gmail might have updated
- Fill manually and press Enter

**Script crashes?**
- Check venv has Playwright: `pip install playwright`
- Install Chrome driver: `playwright install chromium`
